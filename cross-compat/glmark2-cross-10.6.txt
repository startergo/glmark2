# Meson cross file for x86_64-apple-macos10.6 glmark2 builds.
#
# PORTABILITY: /Users/macbookpro/glmark2 below is a placeholder for the absolute path to
# the glmark2 repo root on your machine. Before running `meson setup`,
# replace it. From the repo root:
#
#   sed -i.bak "s|/Users/macbookpro/glmark2|$(pwd)|" cross-compat/glmark2-cross-10.6.txt
#
# Other paths that may need adjustment:
#   - /Applications/Xcode.app/.../MacOSX10.6.sdk  (10.6 SDK location)
#   - /opt/homebrew/opt/llvm/bin/llvm-ar          (Homebrew LLVM bin tools)
#
# Notes:
#   - libc++ 5.0.1 (leopard-webkit-build) is linked STATICALLY into the
#     glmark2-macos executable (libc++.a + libc++abi.a). 10.6 has no
#     system libc++, and an executable can carry its own copy, so unlike
#     the Mesa-VirGL dylib build no -reexport_library / dylib bundling is
#     needed.
#   - <filesystem> resolves to cross-compat/compat-headers/filesystem,
#     which redirects to libc++ 5's header-only <experimental/filesystem>.
#   - clock_gettime_compat.o provides clock_gettime (libc++ 5's
#     steady_clock calls it), strndup, strnlen and open_memstream.
